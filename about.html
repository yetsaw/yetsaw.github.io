技术 · 运作方式

  • 全站为纯静态站点，托管于 GitHub Pages，无服务器、无数据库、无构建步骤，任何静态文件原样即可访问。
  • 目录条目由前端脚本自动读取：依次尝试 GitHub Contents API → 各文件夹下的 manifest.json → 内置占位数据。向对应文件夹提交新文件后，刷新页面即自动出现（受 API 速率限制，约 60 次/小时，页面做了缓存）。
  • 昼夜模式按访问者本地时区自动切换（约 06:00–18:00 为日间），亦可点右上角 ◐ 手动覆盖。
  • 新闻看板的高考倒计时、新年倒计时与最近提交时间均为实时计算。
